# Website BDS - Bootstrap

Phiên bản React + TypeScript + Vite của website BDS, được chuyển từ Material UI sang Bootstrap 5 và CSS Modules.

## Chạy dự án

```bash
npm install
npm run dev
```

Trang dự án: `http://127.0.0.1:4174/du-an/vinhomes-ocean-park-3`

## Công nghệ

- React 19 + TypeScript
- Vite
- Bootstrap 5 và Bootstrap Icons
- CSS Modules cho toàn bộ giao diện tùy biến
